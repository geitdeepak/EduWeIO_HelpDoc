# Course Codes

Each course card carries a short course code. It is the badge in the top-right corner of the course picture, for example **AZR** on Azure Foundation and **CLT** on Cloud Computing.

<figure markdown>
  ![A Cloud Computing course card as it looks when you hover over it, with an arrow pointing at the course code CLT in the top-right corner of the picture, and the course details below](../assets/images/home/home-09-course-code.png){ loading=lazy }
  <figcaption>A card while you hover over it. The course code (here CLT) is in the top-right corner of the picture.</figcaption>
</figure>

Codes seen on the catalog so far:

| Code | Course, as shown on its card |
|---|---|
| `AZR` | Azure Foundation |
| `CLT` | Cloud Computing |
| `DSA` | DSA (Data Structure Using C) |
| `JAV` | Java (Java Programming) |
| `PPS` | C (Programming in C) |
| `PTH` | Python |

On the course demo page, the code also shows a number, for example `PPS 1101` for Programming in C. See [Watch A Demo](watch-a-demo.md).
